# Gothic 3 Stringtable Translator (LM Studio & Tkinter Edition)

Графическая утилита на Python / Tkinter для автоматического поиска и перевода пропущенных строк в файлах `stringtable.ini` игры **Gothic 3** и модов к ней с помощью **локальных нейросетей через LM Studio**.

Форк оригинального проекта [maximal-max/gothic3-stringtable-translator](https://github.com/maximal-max/gothic3-stringtable-translator). В отличие от оригинала, инструмент работает **полностью локально, бесплатно и без API-ключей DeepL**, а также оснащён удобным графическим интерфейсом и пресетами стилей.

---

## ✨ Особенности

* **Полностью локально и бесплатно**: работает через [LM Studio](https://lmstudio.ai/) (любые открытые модели). Никаких платных ключей и лимитов на символы.
* **Кастомные стили и промпты**:
  * 🎙 **В стиле Гоблина (Дмитрий Пучков)** — брутальный, хриплый, оперской слог («камрады», «граждане бандиты»).
  * 🔥 **Божья Искра / Трэш-пародия** — угарный колорит криминальных разборок 90-х («общак», «стрелки», «братки»).
  * 🔞 **Матный 18+ (Каторжный хардкор)** — отборный русский мат без цензуры в духе колонии строгого режима под Барьером.
  * ⚔ **Атмосфера Готики** — каноничный приземленный диалект каторжников с сохранением оригинальных терминов (руда, Белиар, Иннос).
  * 📜 **Классический RPG** — чистый литературный фэнтези-перевод.
  * ✏ **Свой промпт** — полная свобода ручного редактирования системного промпта.
* **Удобный GUI (Tkinter)**:
  * Не зависает при переводе благодаря многопоточности (`threading`).
  * Полноценная поддержка буфера обмена: контекстное меню мыши (ПКМ) и горячие клавиши `Ctrl+C`, `Ctrl+V`, `Ctrl+A` даже на **русской раскладке Windows**.
  * Возможность выбрать как целую папку с модами, так и отдельный распакованный файл `.ini`.
* **Безопасность и совместимость**:
  * Сохранение кодировок (`UTF-16`, `Windows-1251`, `CP1252`, `UTF-8`).
  * Автоматический бэкап оригиналов в папку `_backup/` перед внесением изменений.
  * Атомарная перезапись через временные файлы (никаких битых/недописанных строк).
  * Очистка ответа от символа `;`, чтобы не ломать структуру колонок Gothic 3.
  * Локальный кэш (`translation_cache_llm.json`): повторные строки не отправляются в нейросеть дважды.
* **Zero Dependencies**: не требует установки сторонних библиотек через `pip` — работает на чистом стандартном Python 3.8+.

## 🚀 Быстрый старт

### 1. Подготовка LM Studio
1. Скачайте и запустите [LM Studio](https://lmstudio.ai/).
2. Загрузите желаемую модель.
3. Перейдите во вкладку **Local Server** (значок `<->` слева), выберите модель и нажмите **Start Server** (по умолчанию поднимется на `http://127.0.0.1:1234`).

### 2. Запуск переводчика
Клонируйте репозиторий и запустите скрипт:
```bash
git clone https://github.com/Koaxz/gothic3-stringtable-translator-llm.git
cd gothic3-stringtable-translator-llm
python gothic.py
